This code implements a simple space shooter game using JavaScript and HTML canvas. It defines classes for the player,
enemy invaders, their respective projectiles, and decorative particles. The main animate() function updates and draws these objects,
detects collisions (like projectiles hitting invaders or the player), handles keyboard inputs to move the player or shoot, 
and spawns new enemy grids periodically. The score is tracked and displayed, and the game ends when the player is hit.
